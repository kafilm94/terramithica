# Manuscript

The actual novel text — outline, drafted chapters, and prose excerpts pulled from the
raw logs.

- `outline.md` — Part I series/chapter outline ("The Awakening")
- `chapters/` — individually drafted chapters (currently Ch. 9, Ch. 10)
- `excerpts/` — longer prose passages not yet slotted into a numbered chapter
  (e.g. the Luminara opening excerpt)

As more chapters get drafted, add them to `chapters/` as `chapter-##.md`.
