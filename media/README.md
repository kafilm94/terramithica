# Media

- `prompts/` — AI image-generation prompts used for cover art and character/scene
  illustration (text only)
- `images/` — see the note below

**Note on images:** the actual rendered cover-art images (`.webp`) remain in the
original `/images` folder at the repo root exactly as uploaded — they were not moved
or duplicated into a nested `media/images/` folder to avoid storing large binaries
twice. This `media/` folder is for prompt text and other lightweight media reference
material only.
